核心功能

为串口调试而生的完整工具链

六大工作区覆盖协议配置、实时调试、文件传输、AI 助手——把散落在各个脚本里的工作，收进一个桌面应用。

可视化协议配置

模块地址表、帧格式（帧头 / 帧尾 / 长度 / 校验）、命令字与字段图形化编辑，拖拽卡片即可调整字节顺序，协议即改即生效。

版本管理与导入导出

历史版本自动留存，任意两个版本或两个协议可做 diff 对比；支持协议文件导入导出、按项目归档管理。

变更审核工作流

草稿保存 → 指定审核人 → 提交审核 → 发布生效，全程留痕；修改前后逐项对比，审计日志可导出。

实时串口调试

端口枚举与 USB 热插拔检测，ASCII / HEX 双视图、毫秒级时间戳、自动滚动；MCP 外部客户端的串口活动实时镜像。

协议构帧发送

选择协议与命令字、填写字段值即自动构帧（长度与校验自动计算）；帧预览同时给出原始值、解析值与物理值。

列表发送

编排多条指令按周期自动发送：循环次数、循环间隔、条目间隔独立配置，发送前数据预览，示例一键加载。

文件传输 · AFT-1

自研串口文件传输协议：MTU 分包、滑动窗口、选择性重传、断点续传，CRC16-CCITT 帧校验 + CRC32 整包校验。

自定义看板

拖拽式信号监控画布：传感器、开关量、趋势图组件即拖即用，绑定协议信号，配置触发条件与动作，卡片间可连线。

协议预览文档

帧结构、模块地址、命令定义一键渲染成规范文档，一键复制 Markdown，PDF 样式导出，交付沟通更高效。

AI 助手

OpenAI / Anthropic 双协议兼容，多模型随时切换，SSE 流式输出；提问可自动附带工具内最新协议与串口数据。

MCP 接入

内置 MCP 服务器，Claude Code、Cursor 等 AI 工具直连：18 个工具 + 3 类资源 + 3 个调试模板；写操作弹窗人工确认。

团队协作

SQLite 本地优先，可选团队服务器多端同步；用户与角色权限管理、心跳在线状态、自动更新开箱即用。

GUIDE

快速上手指南

安装、连接串口、创建第一个协议配置——十分钟完成首次联调。

1. 安装后进入「串口通信」，选择串口号与波特率（如 COM3 · 115200 8N1）建立连接。
2. 在「协议配置」新建协议，定义帧头、模块地址、命令字与字段，保存后即时生效。
3. 回到调试页选择协议与命令字即可构帧发送，实时观察设备回复；也可进入「列表发送」编排指令序列，或用「文件发送」通过 AFT-1 传输固件。
完整图文指南内置在应用的「帮助」面板，随时可查。
INTEGRATION

MCP 接入指南

将串口能力接入 Claude Code、Cursor 等 AI 编码助手的完整配置步骤。

在应用「设置」中开启内置 MCP 服务器，复制生成的 stdio 端点配置，粘贴到 AI 客户端的 MCP 配置文件中即可。连接后，AI 客户端可调用 18 个工具：查询协议库、构帧、解析数据、读取串口日志、打开 / 关闭 / 发送串口等；写操作会弹窗人工确认。支持在线桥接与离线只读两种模式，完整配置步骤与常见问题见仓库文档目录。
PROTOCOL

文件传输协议 AFT-1

分包格式、校验机制与进度管理的完整规范，二次开发必备。

AFT-1 面向串口大文件传输设计：按 MTU 分包 + 帧序号 + 滑动窗口，帧级 CRC16-CCITT 校验、整文件 CRC32 校验，支持选择性重传（RESEND）与断点续传，接收端按序号重组并校验完整性。帧格式字段定义与状态机详见仓库中的协议规范文档。
ARCHITECTURE

架构与安全分析

本地优先架构设计、数据边界与安全特性说明。

工具遵循本地优先原则：协议与信号数据存储于本机 SQLite，不经过任何云端同步；AI 助手能力可按需配置，数据边界可控。架构分层、进程模型与安全边界分析详见仓库文档目录。

常见问题

你可能想知道

工具是否收费？

完全免费，且以 MIT License 开源。你可以自由使用、修改和分发。

支持 macOS 或 Linux 吗？

当前版本面向 Windows 10/11（x64）。macOS 与 Linux 支持已在路线图上，欢迎通过反馈渠道投票。

协议数据存储在哪里？会同步到云端吗？

协议与信号数据默认存储在本地 SQLite 数据库中，完全离线可用。工具遵循本地优先原则，未经确认不会上传任何数据。

如何获得版本更新？

应用内置更新检查，启动时若发现新版本会提醒你一键升级。也可以随时在本页「下载」区或 GitHub Releases 获取最新安装包。

可以把协议接入我自己的 AI 工作流吗？

可以。工具内置 MCP 服务器，任何支持 MCP 的 AI 客户端（如 Claude Code、Cursor）都能直接查询协议、读写串口。详见「MCP 接入指南」。
