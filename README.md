## 简介

> 比特在线上律动，协议在屏上清明。

波特律动（BaudLab）是一款面向嵌入式开发的桌面工具——把协议配置、信号管理、实时调试、文件传输收进一个应用，告别靠猜和 print 调串口的时代。本地优先设计，协议数据始终留在你的机器上。

> 本仓库为波特律动官网与发布页源码，安装包通过[官网下载页](https://alvan-1.github.io/BaudLab.io/#download)分发。

## 功能详解

### 1. 串口通信（调试 · 列表发送 · 文件发送）

| 功能点 | 说明 |
|---|---|
| 连接管理 | 端口枚举与 USB 热插拔事件驱动刷新；波特率 / 数据位 / 停止位 / 校验位配置 |
| 协议构帧发送 | 选择协议 → 命令字 → 填写字段值，自动计算长度与校验；也可直接发送 HEX / 文本 |
| 帧预览 | 同一帧同时展示原始值、解析值与物理值 |
| 通信日志 | ASCII / HEX 双格式、毫秒级时间戳、自动滚动、一键清空；「加入发送」快速把日志帧转为发送项 |
| MCP 活动镜像 | 外部 AI 客户端对串口的打开 / 关闭 / 发送实时显示在调试页 |
| 列表发送 | 多条目批量发送：循环次数、循环间隔、条目间隔独立配置，发送前数据预览，示例一键加载 |
| 文件传输（AFT-1） | 按 MTU 自动切块（64–1024 可调）、滑动窗口、块超时 / 帧间隔 / 应答监听可配、期望应答关键字校验、选择性重传、断点续传、CRC16-CCITT 帧校验 + CRC32 整包校验、实时传输日志 |

### 2. 协议配置

## 快速开始：团队服务器 + 管理后台

波特律动默认单机使用；需要多人共享协议数据时，可启动内置的团队数据服务器。

### 1. 启动服务器（约 2 分钟）

1. 在服务器电脑安装 Node.js LTS（要求 22.13 或更高，无需安装任何依赖）
2. 在应用源码目录运行 `启动服务器.bat`（或 `node server.js`）
   - 首次启动自动生成 `server.config.json`（默认端口 3010）
   - 控制台会显示局域网地址，如 `http://192.168.1.100:3010`，成员填这个地址
   - 首次启动若弹出 Windows 防火墙提示，选「允许访问」
3. 数据库文件位于 `server-data/serial_protocol.db`，已内置自动备份（每 24 小时一份，默认保留 14 份）

### 2. 登录管理后台

浏览器访问 `http://127.0.0.1:3010/admin`（仅限服务器本机访问，远程访问会返回 403），可完成：

| 功能 | 说明 |
|---|---|
| 运行状态 | 端口、数据库驱动、运行时长、在线用户列表 |
| 访问令牌 | 设置 / 修改 `server.config.json` 中的 token（留空 = 不鉴权，建议设置随机长串） |
| 邮件服务 | SMTP 配置与测试发信（用于注册验证码、密码重置） |
| 用户管理 | 创建用户、重置验证码、启用 / 禁用、分配部门、删除 |
| 角色权限 | 角色 CRUD 与权限点配置 |
| 数据维护 | 数据库统计、完整性检查、备份列表、立即备份 |
| 运行日志 | 最近 150 条认证 / 网关日志 |

### 3. 成员接入

桌面工具内「数据库连接」页面：模式选「团队服务器」→ 填服务器地址与访问令牌 → 「测试连接」通过后保存配置，即可多端共享协议数据。断开连接时自动进入本地模式，恢复后自动重连。
